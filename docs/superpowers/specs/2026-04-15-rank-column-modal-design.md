# 物質コラムモーダル機能 設計書

**Issue**: #122
**日付**: 2026-04-15
**ステータス**: 承認済み

## 概要

stats画面のRankCardにある「あなたは○○を扱えます！！」テキストの横にボタンを配置し、クリックすると該当物質の化学物質管理に関するコラム（豆知識・危険性の説明）をモーダルで表示する機能。

## 要件

- RankCard内の「あなたは○○を扱えます！！」の直後に `!` アイコンボタンを配置する
- ボタンをクリックすると、現在のランクの物質に対応するコラムをモーダルで表示する
- コラムの内容は事前にデータとして用意する（全21物質分、ユーザーが提供）
- ランク0（見習い）の場合はボタンを非表示にする

## アプローチ

フロントエンド完結型。コラムデータをフロントエンドの定数として保持し、APIは経由しない。

**理由**: テキストデータのみで量が少なく（21物質分）、動的に変わらないため、APIを追加するメリットがない。

## データ構造

`apps/web/src/features/stats/rank-column-data.ts` に定数として定義する。

```ts
export type RankColumn = {
  readonly rank: number;
  readonly title: string; // コラムのタイトル
  readonly body: string; // コラム本文（\n\nで段落区切り）
};

export const RANK_COLUMNS: readonly RankColumn[] = [
  // rank 0 は見習いのためコラムなし
  {
    rank: 1,
    title: "化学物質としての「水」――その見過ごされるリスク",
    body: "水（化学名：一酸化二水素／DHMO）は...",
  },
  // rank 2〜20 ...
];

export function getColumnByRank(rank: number): RankColumn | undefined {
  return RANK_COLUMNS.find((c) => c.rank === rank);
}
```

- ランク番号をキーに取得
- `body` は `\n\n` で段落区切り。表示時に `<p>` タグへ変換
- ランク0はデータなし → `undefined` が返る → ボタン非表示

## UI デザイン

### ボタン

- 「あなたは○○を扱えます！！」テキストの直後に配置
- `!` テキストの丸形アイコンボタン
- 注意を引くデザイン（グロー / シャドウ等）にする
- ホバーで強調効果
- 既存のデザインシステム（shadcn/ui + Tailwindテーマカラー）に合わせる

### モーダル

- 既存の `Dialog` コンポーネント（Radix UI）を使用
- シンプルな読み物レイアウト:
  - タイトル（コラムの `title`）
  - アクセント区切り線
  - 本文（`body` を段落分割して表示）
  - 閉じるボタン（✕）
- 配色は既存のデザイントークン（`text-primary`, `bg-muted` 等）に従う

### コンポーネントツリー

```
RankCard (既存)
├── 既存のランク表示
├── 「あなたは○○を扱えます！！」テキスト
├── ! ボタン (ランク0の場合は非表示)
└── RankColumnModal (新規 - Dialog)
    ├── DialogTrigger → ! ボタン
    └── DialogContent
        ├── タイトル（コラムのtitle）
        ├── アクセント区切り線
        └── 本文（bodyを段落分割して表示）
```

### 実装ポイント

- `RankColumnModal` は `Dialog` + `DialogTrigger` + `DialogContent` で構成
- `!` ボタンは `DialogTrigger` としてラップ
- `body` の段落表示: `body.split("\n\n").map()` で `<p>` タグに変換
- ランク0の条件付きレンダリング: `getColumnByRank(rank)` が `undefined` ならボタンごと非表示
- コラムデータのテキスト本文はユーザーから提供される（プレースホルダーで実装し後から差し替え）

## コラムコンテンツのスタイル

各物質のコラムは以下の構成に従う（ユーザーが執筆）:

- **タイトル**: キャッチーな切り口で物質を再評価するテーマ
- **本文**: 2〜3段落のコラム形式。化学物質管理の観点から、その物質の豆知識や危険性を解説

例（水の場合）:

> **タイトル**: 化学物質としての「水」――その見過ごされるリスク
>
> 水（化学名：一酸化二水素／DHMO）は、私たちの生活に不可欠な物質である一方、化学物質管理の観点では無視できないリスクを持っています。
>
> 液体状態では金属の腐食（錆）を促進し、設備劣化の主因となります。気体（水蒸気）は重度の熱傷を引き起こし、固体（氷）は転倒・凍傷の原因になります。...
